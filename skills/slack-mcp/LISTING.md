Prepared for the Agensi listing (free, non-exclusive, own price, 70% share).

## Blurb

`yt-slack-mcp` gives an agent read and write access to Slack through your own
browser session: read permalinks, threads, channel history, images, and PDF
text, then reply in threads, react, upload files, or edit messages in the
channels you explicitly allow. This skill teaches the agent which of the eight
tools fits each request and keeps it inside the boundaries — read before
writing, mark every post with `🤖 <model>:`, and never write outside the
allow-list.
